# 무료 웹앱 2종

설치·회원가입 없이 브라우저에서 바로 쓰는 웹앱입니다. 모든 데이터는 사용하는 기기의 브라우저(localStorage)에만 저장되고 서버로 전송되지 않습니다.

| 앱 | 경로 | 설명 |
| --- | --- | --- |
| 우리가족 자산 대시보드 | `/asset-dashboard/` | 연금저축·IRP·ISA·일반·해외 계좌를 한 화면에. 순자산, 종목별 통합, 다음 자동매수 예상, 연금저축 세액공제 한도(600만/900만), 미래 예측, `.json` 백업·복원 |
| 무소음 비주얼 타이머 (Focus Disk) | `/focus-disk/` | 남은 시간을 색깔 원판으로 보여 주는 60분 타이머. 완전 무소음/진동/차임벨 3가지 알림, 화면 꺼짐 방지, PWA(홈 화면 설치·오프라인) |
